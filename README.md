## 🚀 Quick Start

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/jeg1303/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   # Create .env file
   cp .env.example .env
   # Add your Gmail App Password to .env
   ```

4. **Run locally**
   ```bash
   npm start
   ```

5. **Open in browser**
   ```
   http://localhost:3000
   ```

## 📧 Email Configuration

The contact form requires Gmail App Password setup:

1. Enable 2-Factor Authentication on your Gmail account
2. Generate an App Password: https://myaccount.google.com/apppasswords
3. Add to `.env` file:
   ```
   EMAIL_PASSWORD=your-app-password-here
   EMAIL_USER=jegannaathan4@gmail.com
   ```

See [EMAIL_SETUP.md](EMAIL_SETUP.md) for detailed instructions.
